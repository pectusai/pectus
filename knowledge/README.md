# Knowledge

This is your data lake. Drop anything here you think helps Pectus understand your audience, your market, or your business. Skills consume what's here.

## Folders

- `raw/` — your uploads. Anything: AnswerThePublic CSVs, BigQuery exports, screenshots, customer interview notes, audience research PDFs. Per-project folders inside (e.g. `raw/uk/`) for project-specific knowledge; root-level files apply to all projects.
- `keywords/` — GSC pulls and uploaded keyword CSVs land here. The `weekly-analysis` skill reads from this folder.
- `insights.md` — generated by the `knowledge-digest` skill. Rerun the skill whenever you add new files to `raw/` so other skills pick up the changes.
- `examples/` — sample files checked into the repo so a fresh install has something to digest. Safe to delete once you've added your own.

## Privacy

`raw/`, `keywords/`, and `insights.md` are gitignored. They never leave your machine unless you push them yourself.

## Adding data

Just drop files in. No naming convention required, but useful conventions help the digest skill:

- Prefix with the project code if it's market-specific: `uk-answers-2026-04.csv`
- Date-stamp where it matters: `bigquery-funnel-2026-04-15.csv`
- Use file extensions the digest skill recognizes: `.csv`, `.json`, `.jsonl`, `.md`, `.txt`, `.pdf`, `.png`, `.jpg`, `.xlsx`

Then run:

```
npx pectus knowledge digest
```

This regenerates `insights.md`. Other skills (`weekly-analysis`, `seo-strategy`, `jobs-to-be-done`) read `insights.md` on their next run.

## What not to put here

- Secrets, credentials, API keys (those go in `.env.local`)
- Files larger than ~50 MB (the digest skill will skip them; instead, summarize externally and drop a small markdown note)
- Anything you wouldn't want a future-you to read on a Monday morning
